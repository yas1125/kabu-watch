# 銘柄ウォッチ

保有・ウォッチ銘柄の騰落率を1ページにまとめて表示する。

## 使い方

銘柄を増減したいときは `watchlist.csv` を編集する。

| 列 | 内容 |
|---|---|
| 区分 | `保有` または `ウォッチ`。画面上で分けて表示される |
| コード | 証券コード（`256A` のような新形式も可） |
| 銘柄名 | 空欄なら英語名が自動で入る |
| 基準日 | `2024-05-10` 形式。空欄なら共通の基準日を使う |
| メモ | 銘柄名の下に小さく表示される |

## 基準日を変える

全銘柄の基準日は `build.mjs` 冒頭の `DEFAULT_BASE_DATE` で決まる。
ここを書き換えれば全銘柄まとめて変わる。銘柄ごとに変えたいときだけ
`watchlist.csv` の基準日欄に日付を書く（そちらが優先される）。

## 一言コメントについて

各行に付く「3日続伸」「反落」などは、直近の終値の並びから機械的に判定している。
値動きの言い換えであって、割安・割高や売買の判断は含まない。

| 表示 | 条件 |
|---|---|
| 急騰 / 急落 | 前日比が ±5% 以上 |
| N日続伸 / N日続落 | 同じ方向に3日以上続いた |
| 小動き | 直近5日すべて ±0.5% 未満 |
| 反発 / 反落 | 前日と逆方向に動いた |
| 変わらず | 前日比が 0% |

手元で更新するとき:

```
node build.mjs
```

`docs/index.html` が作り直される。

## 仕組み

- 株価は Yahoo Finance の終値。追加ライブラリは使っていない
- 平日18時（JST）に GitHub Actions が自動実行し、更新結果をコミットする
- `docs/` を GitHub Pages が配信する

## 銘柄リストをGoogleスプレッドシートで管理する場合

スプレッドシートを「ウェブに公開」してCSV形式のURLを発行し、
リポジトリの Settings → Secrets and variables → Actions → Variables に
`WATCHLIST_URL` という名前で登録する。設定すると `watchlist.csv` より優先される。
